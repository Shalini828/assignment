# SecureID – Authentication Flow

A responsive authentication and multi-factor verification interface built with Next.js and Tailwind CSS.

## Features

- User registration
- Email OTP verification
- Mobile OTP verification
- SMS OTP verification
- MFA method selection
- Authenticator app setup
- QR code setup
- Authenticator code verification
- OTP expiration timer
- Resend OTP functionality
- Maximum attempt handling
- Registration success screen
- Responsive UI

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Next.js App Router

## Authentication Flow

Register → Email Verification → Mobile Verification → MFA Setup → Authenticator/SMS Verification → Registration Success

npm install
npm run dev
